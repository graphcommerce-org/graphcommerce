# @graphcommerce/oxfmt-config-pwa

The oxfmt configuration of GraphCommerce. Add `oxfmt.config.mts` to the root of
the project:

```ts
export { default } from '@graphcommerce/oxfmt-config-pwa'
```

`@graphcommerce/oxfmt-config-pwa/classic` has the same options without import
sorting and JSDoc formatting.
